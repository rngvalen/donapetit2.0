MODELOS NUEVOS:
1. /app/model/Catalogo.php

Maneja el catálogo de productos predefinidos
Métodos principales:

obtenerProductosActivos() - Lista productos del catálogo
obtenerPorId() - Obtiene un producto específico



2. /app/model/ProductoDonante.php

Maneja el inventario de cada donante
Métodos principales:

registrarProducto() - Agrega producto al inventario del donante
obtenerInventarioDonante() - Lista productos del donante
obtenerTodosDisponibles() - Lista productos de todos los donantes (para receptor)
actualizarCantidad() - Modifica cantidad de un producto
eliminarProducto() - Marca producto como inactivo




🎮 CONTROLADORES MODIFICADOS:
1. /app/controllers/ProductoController.php

Se actualizó completamente para usar los nuevos modelos
Métodos clave (sin solicitudes):

index() - Redirige a misProductos
misProductos() - Vista del inventario del donante
create() - Formulario para cargar productos
store() - Guarda producto en el inventario
destroy() - Elimina producto del inventario
edit() y update() - Editar cantidad de productos
productosDisponibles() - Vista de productos para receptor




🎨 VISTAS NUEVAS:
1. /app/view/products/product_load.php

Formulario para que el donante cargue productos
Muestra productos del catálogo agrupados por categoría
Campos: producto (select), cantidad, fecha de vencimiento

2. /app/view/products/my_products.php

Lista el inventario del donante
Muestra: nombre, cantidad, categoría, fecha vencimiento
Botones: agregar producto, eliminar

3. /app/view/products/available_products.php

Lista productos disponibles de todos los donantes
Para receptores
Agrupado por categoría
Muestra: producto, donante, cantidad disponible
